# Faysal Glass — AGENTS.md

## Stack

- **PHP 7/8** procedural, no framework, no composer
- **MySQL** via `mysqli_*` functions
- **Frontend**: Bootstrap 4.6, SB Admin 2, jQuery 3.6, Font Awesome 6, SweetAlert2 — all loaded from CDN
- **No build tools, no tests, no CI/CD, no `.htaccess`**

## Entry & Auth

- `index.php` redirects to `login.php` (or `dashboard/dashboard.php` if session active)
- Session-based auth with **plain text passwords** (see `login.php:7` comment)
- Every page gates on `$_SESSION['user_id']` + `$_SESSION['logged_in']` before rendering; some (accounts/, customers/, reports/) check only `user_id`
- `includes/sidebar.php` also checks auth at the top — any page that includes it does a second gate

## Required includes

Every page needs (include path depends on depth; subdirectory pages use `../`):
```php
include('../includes/database.php');  // $conn (mysqli), executePrepared(), escapeString()
include('../includes/txt.php');       // $software_name, $currency_symbol, formatCurrency()
```
Include order does not matter. `footer.php` calls `closeConnection()` automatically.

## Architecture

Modules live in top-level directories with 3–10 PHP files each (no router, no controllers). Key dirs:

| Dir | Purpose |
|-----|---------|
| `dashboard/` | One file — `dashboard.php` |
| `sales/`, `purchases/`, `quotations/` | Add/view/print/refund (save handlers are AJAX endpoints returning JSON) |
| `products/` | Product list, opening stock, categories, companies, units |
| `customers/`, `suppliers/`, `employees/` | Ledgers with payment/receipt sub-pages |
| `accounts/` | Cashbook, dynamic bank ledgers, withdraw, transfer, manage bank accounts |
| `reports/` | 9 report files — sale, purchase, profit/loss, inventory, invoice, refund, customer, supplier, salary |
| `includes/` | `database.php`, `txt.php`, `header.php`, `sidebar.php`, `footer.php` |

## Conventions

- **DB**: `faysal_glass` / `localhost` / `root` / no password / `utf8mb4`
- **Timezone**: `Asia/Karachi` (`database.php:28`)
- **Currency**: PKR (₨) — use `formatCurrency($amount)` (`txt.php:44`)
- **Page title**: set `$page_title` before including `header.php`
- **AJAX endpoints**: return `{success: bool, message: string}`, suppress output before JSON with `error_reporting(0)` at the top
- **Sales/purchases**: `mysqli_begin_transaction` + try/catch + commit/rollback
- **Inventory**: glass measured in sq ft via `client_height`, `client_width`, `std_height`, `std_width`
- **Hold bills**: incomplete sales in `hold_sales_master` / `hold_sales_details`, loaded back into `add_sale.php`
- **No migrations**: schema must exist manually; no SQL files in repo
- **`error_log` files**: generated by PHP in several dirs, not committed (no `.gitignore`)
